# RRB JE Prep

A personal preparation platform for **RRB JE 2026**, starting with CBT-1 Current Affairs practice.

## Roadmap

- CBT-1 Current Affairs
- CBT-1 Mathematics
- CBT-1 Reasoning
- CBT-1 General Science
- CBT-1 General Awareness
- PYQ practice
- Mock tests
- Revision and weak-topic tracking
- Later: CBT-2 subjects and Mechanical Engineering

## Current version

The first version is a lightweight static web app with:
- 10-question MCQ test
- A/B/C/D options
- Score tracking
- Answer explanations
- Retry-incorrect mode
- Responsive mobile layout

## Run locally

Open `index.html` in a browser.

## Note

The initial question bank contains interface/demo questions. It should be replaced with verified, date-specific current-affairs questions before being used as an exam-preparation source.
